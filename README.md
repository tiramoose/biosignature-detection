# Biosignature Detection Pipelin e

A Monte Carlo simulation framework for estimating the detectability of atmospheric biosignatures on rocky planets with JWST and future telescopes. 

## Status 
Week 1-2 in progress: pipeline skeleton 

## Project Structure 
- 'src/' - core pipeline modules
- 'config/' - experimental configuraiton files
- 'data/templates/' - atmosphere template spectra
- 'notebooks/' - analysis and demo notebooks
- 'paper/' - manuscript in progress
